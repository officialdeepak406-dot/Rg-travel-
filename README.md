# RG Tempo Traveller — Premium V7

Premium responsive travel website redesign for Chennai group travel.

- Removed Innova from the fleet.
- Added 12, 14, 16, 18, 21 and 25 seater Tempo Traveller fleet.
- Vehicle detail modal with capacity, AC, luxury seating, music system, DJ light note and use cases.
- View Details + Book buttons for every vehicle.
- Booking form collects name, WhatsApp/phone, date, travellers, vehicle, trip type, destination, pickup and requirements.
- Booking details are formatted into a WhatsApp message.
- Auto-moving fleet, trip and city sliders with manual arrows.
- Mobile-first responsive layout and mobile menu.
- White premium theme with navy/gold accents.
- Smooth hero slider, reveal animations and hover effects.
- No chatbot.
